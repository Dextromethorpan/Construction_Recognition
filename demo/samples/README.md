# Sample photos

The 9 input photos behind `demo/examples/` (same order and names). Try the demo on them:

    python demo/demo.py demo/samples --out demo_out

All are real photos from the `val_v2` split (not from the test set, no CS10k, no synthetic images). Truth labels and the reason each photo was chosen are in `demo/examples/README.md`.

Licence: all come from Roboflow Universe datasets under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Files are unchanged, only renamed.
- 01, 02, 05, 06, 08, 09: Scaffold 0726 (Archikhu), Roboflow Universe archikhu/scaffold-0726-ddew4
- 03, 04, 07: scaffold (ESCO), Roboflow Universe esco-7veqt/scaffold-7bi3u
